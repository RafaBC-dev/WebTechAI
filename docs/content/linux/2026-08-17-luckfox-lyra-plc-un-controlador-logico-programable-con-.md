# Luckfox Lyra PLC: un controlador lógico programable con Linux y Wi-Fi

## Introducción

Luckfox ha lanzado el Lyra PLC, un controlador lógico programable con Linux y Wi-Fi que ofrece una amplia gama de conectividad y funcionalidades para aplicaciones industriales.

## ¿Qué es?

El Luckfox Lyra PLC es un controlador lógico programable que se basa en un SoC Rockchip RK3506B con tres núcleos Arm Cortex-A7, ofreciendo una potente plataforma para aplicaciones industriales. Se ejecuta un sistema operativo basado en Debian 12 y Linux 6.1, y admite la instalación de Node-RED, OpenPLC y otras herramientas.

## ¿Cómo funciona?

El Lyra PLC cuenta con una amplia gama de conectividad, incluyendo Wi-Fi 6 y Bluetooth 5.2, así como dos puertos Ethernet y varios conectores para I/O, como RS232, RS422, RS485, CAN bus y relays. También cuenta con una pantalla táctil de 1.9 pulgadas y una variedad de conectores para I2C, GPIO y depuración.

## ¿Por qué importa?

El Lyra PLC es importante porque ofrece una plataforma flexible y potente para aplicaciones industriales, permitiendo a los desarrolladores crear soluciones personalizadas para controlar y monitorear procesos industriales. También es compatible con una amplia gama de protocolos y herramientas, lo que lo hace ideal para integrarse en sistemas existentes.

## Consejo técnico

Si estás interesado en implementar el Lyra PLC en tu proyecto, considera utilizar Node-RED para crear flujos de trabajo y automatizar tareas. Puedes instalar Node-RED en el Lyra PLC y crear flujos de trabajo personalizados para controlar y monitorear tus procesos industriales.

```bash
sudo apt-get install nodered
```

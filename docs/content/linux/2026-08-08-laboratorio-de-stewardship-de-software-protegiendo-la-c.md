## Introducción

El Laboratorio de Stewardship de Software, una organización sin fines de lucro con sede en Escocia, acaba de anunciar su existencia con el objetivo de proteger la cadena de suministro de código abierto. Su misión es identificar y monitorear en tiempo real los paquetes de código abierto críticos del mundo, incluyendo partes ocultas del gráfico de dependencias.

## ¿Qué es?

El Laboratorio de Stewardship de Software es una organización sin fines de lucro que se enfoca en la seguridad de la cadena de suministro de código abierto y la sostenibilidad de los proyectos de código abierto. Su objetivo principal es identificar y monitorear en tiempo real los paquetes de código abierto críticos del mundo, incluyendo partes ocultas del gráfico de dependencias.

## ¿Cómo funciona?

El Laboratorio está trabajando en un observatorio que permite a los usuarios identificar y monitorear en tiempo real los paquetes de código abierto críticos. También están estudiando el efecto del agotamiento de los mantenedores de código abierto y cómo la inteligencia artificial está afectando este problema. Además, están trabajando con universidades para enseñar a la próxima generación de expertos en cadena de suministro de código abierto.

## ¿Por qué importa?

La seguridad de la cadena de suministro de código abierto es fundamental para evitar vulnerabilidades y ataques cibernéticos. El Laboratorio de Stewardship de Software está trabajando para proteger a los desarrolladores y usuarios de código abierto de estos riesgos. Además, su trabajo también tiene un impacto en la sostenibilidad de los proyectos de código abierto, lo que es crucial para el crecimiento y la innovación en la industria del software.

## Consejo técnico

Si eres un desarrollador de código abierto, puedes utilizar herramientas como Dependabot para monitorear y actualizar tus dependencias de código abierto. Dependabot es una herramienta de código abierto que utiliza inteligencia artificial para identificar y actualizar tus dependencias de código abierto de manera automática.

```bash
dependabot update --dry-run
```

# Google Chrome ahora está disponible para Arm Linux en Raspberry Pi 5

**Fecha:** 2026-08-17
**Categoría:** linux
**Tags:** linux, robotica, codigo
**Título original:** Google Chrome is now available for Arm Linux. We tested it on a Raspberry Pi 5

---

## Introducción

Google Chrome, el popular navegador web, ha sido portado a Arm Linux y se puede instalar en Raspberry Pi 5. Esto significa que los usuarios de esta plataforma pueden disfrutar de características como la sincronización de contraseñas y marcadores.

## ¿Qué es?

Google Chrome es un navegador web desarrollado por Google que ofrece una experiencia de usuario rica y segura. Ahora está disponible para Arm Linux, lo que permite a los usuarios de plataformas como Raspberry Pi 5 utilizarlo.

## ¿Cómo funciona?

Para instalar Google Chrome en Raspberry Pi 5, es necesario descargar el archivo de instalación y ejecutar el comando `dpkg -i` para instalarlo. Una vez instalado, el navegador se puede ejecutar de manera normal.

## ¿Por qué importa?

La disponibilidad de Google Chrome en Arm Linux es importante porque permite a los usuarios de plataformas como Raspberry Pi 5 disfrutar de características como la sincronización de contraseñas y marcadores, lo que puede ser útil para aquellos que utilizan múltiples dispositivos.

## Consejo técnico

Si deseas instalar Google Chrome en tu Raspberry Pi 5, asegúrate de cambiar `amd64` a `arm64` en la URL de descarga para obtener el archivo de instalación correcto.

```bash
wget https://dl.google.com/linux/direct/google-chrome-stable_current_arm64.deb
sudo dpkg -i google-chrome-stable_current_arm64.deb
```

# Consejo de empaquetado de Python: candidatos anunciados

## Introducción

La comunidad de Python ha anunciado a los candidatos que se postularán para el consejo de empaquetado de Python. Este consejo es responsable de desarrollar y mantener las herramientas de empaquetado de Python, que son fundamentales para la distribución y gestión de paquetes de software. La elección de los candidatos es crucial para determinar el futuro de las herramientas de empaquetado de Python.

## ¿Qué es?

El consejo de empaquetado de Python es un grupo de desarrolladores que se encarga de desarrollar y mantener las herramientas de empaquetado de Python, como pip y setuptools. Estas herramientas permiten a los desarrolladores crear, distribuir y gestionar paquetes de software de manera eficiente y segura.

## ¿Cómo funciona?

El consejo de empaquetado de Python está compuesto por cinco miembros que se eligen por votación. Los candidatos se postulan para ocupar uno de los cinco escaños disponibles y los dos candidatos que reciban la mayor cantidad de votos serán designados como Cohorte A con un mandato de dos años, mientras que los tres candidatos siguientes serán designados como Cohorte B con un mandato de un año.

## ¿Por qué importa?

La elección de los candidatos para el consejo de empaquetado de Python es importante porque determinará el futuro de las herramientas de empaquetado de Python. Estas herramientas son fundamentales para la distribución y gestión de paquetes de software y su desarrollo y mantenimiento son críticos para la comunidad de Python.

## Consejo técnico

Si te interesa participar en la elección de los candidatos para el consejo de empaquetado de Python, debes registrarte como miembro votante de la Python Software Foundation antes del 25 de agosto. Luego, podrás votar en la elección del 1 al 15 de septiembre.

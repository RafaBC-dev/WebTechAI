## Introducción

El mini PC GEEKOM IT13 Max ha sido probado con varios sistemas operativos, pero ahora es el turno de Ubuntu 26.04. En este artículo, exploraremos la experiencia de instalar y utilizar Ubuntu en este dispositivo.

## ¿Qué es?

Ubuntu 26.04 es una distribución de Linux basada en Debian, diseñada para ser fácil de usar y personalizar. Es compatible con una amplia variedad de hardware y software, lo que la hace ideal para uso en mini PCs como el GEEKOM IT13 Max.

## ¿Cómo funciona?

Para instalar Ubuntu 26.04 en el GEEKOM IT13 Max, se redujo la partición de Windows 11 y se insertó una unidad USB con la imagen de instalación de Ubuntu. El proceso de instalación fue fluido y sin problemas. Una vez instalado, se puede acceder a la información del sistema mediante la herramienta inxi.

## ¿Por qué importa?

La instalación de Ubuntu 26.04 en el GEEKOM IT13 Max permite a los usuarios aprovechar al máximo la potencia de este dispositivo, ya que Ubuntu ofrece una amplia variedad de herramientas y aplicaciones para realizar tareas de productividad, entretenimiento y más.

## Consejo técnico

Si deseas instalar Ubuntu 26.04 en tu propio dispositivo, asegúrate de reducir la partición de tu sistema operativo existente y crear una unidad USB con la imagen de instalación de Ubuntu. Luego, sigue los pasos de instalación para tener Ubuntu funcionando en tu dispositivo.

```bash
inxi -Fc0
```

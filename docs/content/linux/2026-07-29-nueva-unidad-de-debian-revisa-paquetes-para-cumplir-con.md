# Nueva Unidad de Debian Revisa Paquetes para Cumplir con DFSG

## Introducción

La unidad de Debian, DFSG team, ha sido creada para revisar paquetes en la cola de espera y asegurarse de que cumplan con las Directrices de Software Libre de Debian. Esto es importante para mantener la integridad del sistema operativo.

## ¿Qué es?

La unidad de Debian, DFSG team, es un equipo creado en octubre de 2025 para revisar paquetes en la cola de espera de Debian. Su objetivo es asegurarse de que los paquetes cumplan con las Directrices de Software Libre de Debian, lo que garantiza que el software sea libre y abierto.

## ¿Cómo funciona?

La unidad de Debian revisa los paquetes en la cola de espera para asegurarse de que cumplan con las Directrices de Software Libre de Debian. Esto incluye revisar la licencia del software, la documentación y la compatibilidad con otros paquetes. Si un paquete no cumple con las directrices, no se permite que entre en el archivo de Debian.

## ¿Por qué importa?

La unidad de Debian es importante porque garantiza que los paquetes en el sistema operativo cumplan con las Directrices de Software Libre de Debian. Esto significa que el software es libre y abierto, lo que permite a los usuarios personalizar y modificar el software según sus necesidades.

## Consejo técnico

Si deseas contribuir a la unidad de Debian, puedes unirte al equipo y ayudar a revisar paquetes. Puedes empezar por revisar la documentación de Debian y aprender sobre las Directrices de Software Libre.

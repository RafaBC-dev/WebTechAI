# Construye tu propia televisión mecánica con el proyecto Scanwheel

**Fecha:** 2026-08-05
**Categoría:** linux
**Tags:** robotica, microcontroladores, software y linux
**Título original:** A drum style mechanical television you can build yourself

## Introducción

El proyecto Scanwheel permite a los entusiastas de la robótica y la electrónica construir su propia televisión mecánica, aprovechando la tecnología de Raspberry Pi y MicroPython.

## ¿Qué es?

Scanwheel es un proyecto de televisión mecánica que se basa en un tambor de escaneo, que permite mostrar imágenes en cinco ventanas laterales separadas. Cada ventana tiene su propia pantalla LED y puede mostrar una imagen independiente.

## ¿Cómo funciona?

El proyecto utiliza el hardware PIO del Raspberry Pi Pico para controlar las pantallas LED, lo que permite una resolución horizontal muy alta y una calidad de imagen mejorada. El software se programa en MicroPython y utiliza la biblioteca de MicroPython para controlar el hardware.

## ¿Por qué importa?

El proyecto Scanwheel es importante porque muestra la posibilidad de construir una televisión mecánica personalizada utilizando tecnologías de código abierto y hardware accesible. Esto puede inspirar a los entusiastas de la electrónica y la robótica a crear sus propios proyectos innovadores.

## Consejo técnico

Si deseas construir tu propia televisión mecánica con Scanwheel, asegúrate de seguir las instrucciones del proyecto en GitHub y de utilizar la biblioteca de MicroPython para controlar el hardware.

```bash
import machine
machine.PIO()
```

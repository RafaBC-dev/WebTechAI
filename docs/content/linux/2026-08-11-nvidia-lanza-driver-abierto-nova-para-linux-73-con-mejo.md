# NVIDIA lanza driver abierto 'Nova' para Linux 7.3 con mejoras significativas

**Fecha:** 2026-08-11
**Categoría:** linux
**Tags:** ia-local, linux, codigo
**Título original:** Open-Source NVIDIA "Nova" Driver Sees More Functionality For Linux 7.3

---

## Introducción

NVIDIA ha enviado una actualización importante para su driver abierto 'Nova' para Linux 7.3, que incluye mejoras significativas en la compatibilidad con GPUs NVIDIA y la integración con el lenguaje de programación Rust.

## ¿Qué es?

El driver abierto 'Nova' es un proyecto de NVIDIA para crear un driver de kernel para Linux que sea compatible con GPUs NVIDIA. Es el sucesor del proyecto Nouveau y está diseñado para ser más rápido y eficiente que su predecesor.

## ¿Cómo funciona?

El driver 'Nova' utiliza el lenguaje de programación Rust para crear un kernel de driver que sea seguro y escalable. Incluye mejoras en la compatibilidad con GPUs NVIDIA, incluyendo el soporte para el proceso de arranque del GPU System Processor (GSP) y el formato de imagen de firmware TLV.

## ¿Por qué importa?

La actualización del driver 'Nova' es importante porque brinda mejoras significativas en la compatibilidad con GPUs NVIDIA y la integración con el lenguaje de programación Rust. Esto permitirá a los desarrolladores crear aplicaciones más rápidas y eficientes que utilicen GPUs NVIDIA.

## Consejo técnico

Si estás utilizando un sistema con GPU NVIDIA y deseas aprovechar las mejoras del driver 'Nova', asegúrate de actualizar tu sistema a Linux 7.3 y verificar que tu GPU esté compatible con el driver.

```bash
drm-rust
```

# Elecrow ThinkNode M9: un terminal de comunicación LoRa con teclado QWERTY y pantalla de color

**Categoría:** linux
**Tags:** esp32, robotica, embebidos

## Introducción

Elecrow ha lanzado el ThinkNode M9, un terminal de comunicación LoRa que combina una pantalla de color, un teclado QWERTY físico y conectividad Wi-Fi y Bluetooth. Este dispositivo es ideal para comunicaciones fuera de línea y de emergencia.

## ¿Qué es?

El ThinkNode M9 es un terminal de comunicación LoRa que se ejecuta en firmware MeshCore y cuenta con una pantalla de color, un teclado QWERTY físico, GPS, conectividad LoRa, Wi-Fi y Bluetooth. Está diseñado para comunicaciones fuera de línea y de emergencia.

## ¿Cómo funciona?

El dispositivo está basado en un ESP32-S3R8 y un módulo LoRa Semtech LR1110 que soporta frecuencias US915 y EU868. El ESP32-S3 agrega conectividad Wi-Fi 4 y Bluetooth 5.0/BLE. La pantalla es una 2.4 pulgadas de 240x320 TFT LCD y cuenta con un teclado QWERTY físico de 37 teclas.

## ¿Por qué importa?

El ThinkNode M9 es ideal para comunicaciones fuera de línea y de emergencia, como exploración al aire libre, comunicaciones de emergencia y científicas, y comunicaciones remotas. También es útil para comunidades que buscan comunicarse de manera privada.

## Consejo técnico

Si deseas desarrollar firmware personalizado para el ThinkNode M9, puedes utilizar C/C++ o MicroPy. Recuerda que el dispositivo viene con MeshCore firmware preinstalado.

```bash
micropython
```

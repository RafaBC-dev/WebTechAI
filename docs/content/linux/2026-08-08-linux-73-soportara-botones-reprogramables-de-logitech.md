# Linux 7.3 soportará botones reprogramables de Logitech

**Fecha:** 2026-08-08
**Categoría:** linux
**Tags:** linux, robotica, herramientas
**Título original:** Linux 7.3 To Support Logitech HID++ 2.0 Reprogrammable Button Support

---

## Introducción

La próxima versión de Linux, Linux 7.3, traerá soporte para los botones reprogramables de los dispositivos de entrada de Logitech. Esto permitirá a los usuarios personalizar y remapear los botones de sus ratones y teclados.

## ¿Qué es?

El protocolo HID++ 2.0 es una tecnología de dispositivo que permite a los dispositivos de entrada de Logitech reportar controles reprogramables. Esto significa que los usuarios pueden personalizar y remapear los botones de sus dispositivos de entrada para adaptarse a sus necesidades específicas.

## ¿Cómo funciona?

El kernel de Linux 7.3 incluirá un driver de kernel llamado logitech-hidpp que soportará la tecnología HID++ 2.0. Este driver permitirá a los usuarios remapear y personalizar los botones de sus dispositivos de entrada de Logitech. El driver también incluirá una función para divertir los controles reprogramables, lo que significa que se pueden enviar notificaciones especiales en lugar de eventos de tecla estándar.

## ¿Por qué importa?

Este soporte para botones reprogramables de Logitech es importante porque permite a los usuarios personalizar y adaptar sus dispositivos de entrada a sus necesidades específicas. Esto puede ser especialmente útil para los usuarios que necesitan acceder a funciones específicas de sus aplicaciones o que quieren mejorar su productividad.

## Consejo técnico

Si tienes un dispositivo de entrada de Logitech que soporta la tecnología HID++ 2.0, puedes probar el driver logitech-hidpp en Linux 7.3 para personalizar y remapear los botones de tu dispositivo. Puedes encontrar más información sobre el driver y la tecnología HID++ 2.0 en la documentación oficial de Logitech.

```bash
sudo apt-get install logitech-hidpp
```

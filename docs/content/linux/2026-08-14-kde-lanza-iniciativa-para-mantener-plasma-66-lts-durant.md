# KDE lanza iniciativa para mantener Plasma 6.6 LTS durante tres años

**Fecha:** 2026-08-14
**Categoría:** linux
**Tags:** linux, kde, plasma
**Título original:** KDE, Techpaladin & Kubuntu Focus Announce The Bullet-Proof KDE Software Initiative

---

## Introducción

KDE, Techpaladin y Kubuntu Focus han anunciado una colaboración para mantener la versión LTS de Plasma 6.6 durante tres años, proporcionando actualizaciones de seguridad y correcciones de bugs. Esto es importante porque garantiza la estabilidad y seguridad del entorno de escritorio de KDE.

## ¿Qué es?

La iniciativa 'Bullet-Proof KDE Software' es un esfuerzo conjunto de KDE, Techpaladin y Kubuntu Focus para mantener la versión LTS de Plasma 6.6 durante tres años. Esto incluye la versión de Plasma 6.6 LTS, las bibliotecas de KDE Frameworks y las aplicaciones de KDE Gear. El objetivo es proporcionar actualizaciones de seguridad y correcciones de bugs para mantener la estabilidad y seguridad del entorno de escritorio de KDE.

## ¿Cómo funciona?

La iniciativa se llevará a cabo a través de una colaboración entre KDE, Techpaladin y Kubuntu Focus. Kubuntu Focus proporcionará $100.000 en pagos directos a Techpaladin durante tres años para trabajar en la versión 'bullet-proof' de KDE. Además, Kubuntu Focus patrocinará a KDE e.V. para agregar tres nodos adicionales para pruebas de CI en Kubuntu 26.04 LTS durante tres años.

## ¿Por qué importa?

Esta iniciativa es importante porque garantiza la estabilidad y seguridad del entorno de escritorio de KDE durante tres años. Esto es especialmente relevante para usuarios que dependen de la versión LTS de Plasma 6.6 para su trabajo o actividades diarias.

## Consejo técnico

Si estás utilizando la versión LTS de Plasma 6.6, puedes verificar la disponibilidad de actualizaciones de seguridad y correcciones de bugs en el sitio web de KDE. También puedes configurar tus repositorios para recibir actualizaciones automáticas de la versión 'bullet-proof' de KDE.

```bash
sudo apt update && sudo apt full-upgrade
```

# Un teclado sin teclas: cómo enviar texto a un ordenador a través de audio

**Fecha:** 2026-08-11
**Categoría:** linux
**Tags:** robotica, microcontroladores, software-y-linux
**Título original:** A Keyboard with No Keys

---

## Introducción

Un ingeniero ha creado un sistema que permite enviar texto a un ordenador a través de audio, utilizando un smartphone y un módulo de audio. Esto podría revolucionar la forma en que interactuamos con nuestros dispositivos

## ¿Qué es?

El sistema consiste en un smartphone que envía señales de audio a un módulo de audio, que a su vez las convierte en texto y las envía a un ordenador como un dispositivo USB. Esto permite enviar texto sin necesidad de un teclado físico

## ¿Cómo funciona?

El sistema utiliza un protocolo personalizado para enviar señales de audio de 1 a 4 bits, que son decodificadas por el módulo de audio y enviadas al ordenador como un dispositivo USB. El módulo de audio utiliza un Arduino Micro para procesar las señales de audio y enviarlas al ordenador

## ¿Por qué importa?

Esto podría revolucionar la forma en que interactuamos con nuestros dispositivos, especialmente para personas con discapacidades físicas que no pueden utilizar un teclado físico. También podría ser utilizado en aplicaciones de seguridad, como la autenticación de usuarios

## Consejo técnico

Si deseas crear un sistema similar, puedes utilizar el protocolo personalizado creado por el ingeniero y adaptarlo a tus necesidades. También puedes utilizar herramientas como Arduino IDE para programar el módulo de audio

```bash
Arduino IDE
```

## Introducción

Vishal Soni ha creado un reloj inteligente llamado ChronoWatch X2040, que se destaca por su diseño minimalista y su capacidad para mostrar múltiples relojes en pantalla. Este proyecto utiliza un módulo de pantalla circular con un microcontrolador RP2040 y un sensor de aceleración y giroscopio.

## ¿Qué es?

El ChronoWatch X2040 es un reloj inteligente que utiliza un módulo de pantalla circular con un microcontrolador RP2040 y un sensor de aceleración y giroscopio. Este proyecto tiene como objetivo crear un reloj que sea simple y fácil de usar, sin distracciones innecesarias como notificaciones y seguimiento de pasos.

## ¿Cómo funciona?

El ChronoWatch X2040 utiliza un módulo de pantalla circular con un microcontrolador RP2040, que es un procesador de 32 bits con soporte para C y Python. El módulo también incluye un sensor de aceleración y giroscopio para detectar movimientos. El reloj se alimenta de una batería de 950mAh y tiene una pantalla táctil para interactuar con el usuario.

## ¿Por qué importa?

El ChronoWatch X2040 importa porque muestra la posibilidad de crear un reloj inteligente minimalista y fácil de usar, sin necesidad de una gran cantidad de características y aplicaciones. Esto puede ser especialmente útil para aquellos que buscan un reloj simple y práctico.

## Consejo técnico

Si deseas crear un proyecto similar, te recomendamos utilizar el Pico SDK para programar el microcontrolador RP2040 y el módulo de pantalla circular. También es recomendable utilizar una herramienta de diseño de circuitos como Tinkercad para crear el caso del reloj.

```bash
sudo apt-get install pico-sdk
```

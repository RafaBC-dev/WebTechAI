# Identifica pájaros con un Raspberry Pi y un micrófono USB

**Fecha:** 2026-08-09
**Categoría:** embebidos
**Tags:** robotica, linux, codigo, ia-local
**Título original:** Track Bird Visitors With a Raspberry Pi and a USB Mic

---

## Introducción

Un proyecto llamado Avian Visitors utiliza un Raspberry Pi y un micrófono para identificar y contar los pájaros que visitan tu hogar. La información se muestra en una interfaz web y en una pantalla E-Ink que muestra una imagen de los pájaros más recientes.

## ¿Qué es?

Avian Visitors es un proyecto que utiliza un Raspberry Pi y un micrófono USB para identificar y contar los pájaros que visitan tu hogar. El proyecto utiliza la tecnología de aprendizaje automático de BirdNET para identificar más de 11.000 especies de pájaros basándose en sus sonidos.

## ¿Cómo funciona?

El proyecto utiliza un Raspberry Pi y un micrófono USB para grabar los sonidos de los pájaros que visitan tu hogar. Luego, el proyecto utiliza la tecnología de aprendizaje automático de BirdNET para identificar los pájaros y mostrar su imagen en una interfaz web y en una pantalla E-Ink. La pantalla E-Ink muestra una imagen de los pájaros más recientes y la interfaz web muestra información detallada sobre los pájaros que han visitado tu hogar.

## ¿Por qué importa?

Este proyecto es importante porque permite a las personas identificar y contar los pájaros que visitan su hogar, lo que puede ser útil para científicos, ornitólogos y personas que quieren aprender sobre los pájaros que viven en su área.

## Consejo técnico

Si quieres implementar este proyecto en tu hogar, asegúrate de utilizar la librería BirdNET y la plataforma de aprendizaje automático de Cornell, que es la base del proyecto Avian Visitors.

```bash
pip install birdnet
```

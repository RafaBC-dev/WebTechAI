# Dispositivo de EEG inalámbrico para jugar juegos con señales cerebrales

## Introducción

Un equipo de desarrolladores ha creado un dispositivo inalámbrico de EEG que permite jugar juegos con solo pensar, sin necesidad de manos o implantes. Este dispositivo, llamado Octopus 16, es una herramienta revolucionaria que abre nuevas posibilidades para la interacción humo-computadora.

## ¿Qué es?

El Octopus 16 es un dispositivo de señalización biológica inalámbrico diseñado para la placa de desarrollo XIAO ESP32-S3. Se trata de una herramienta que permite a los usuarios jugar juegos utilizando señales cerebrales (EEG) sin necesidad de manos o implantes. El dispositivo cuenta con 16 electrodos para medir señales biológicas, incluyendo EEG, EMG y ECG.

## ¿Cómo funciona?

El Octopus 16 funciona conectando el dispositivo a una placa de desarrollo XIAO ESP32-S3 o XIAO ESP32-C6, que actúa como un gamepad HID BLE. El dispositivo utiliza 18 pines de contacto con la cabeza para medir las señales cerebrales. El software del proyecto es de código abierto y se puede encontrar en GitHub, mientras que la documentación de hardware y software se puede encontrar en el sitio web de PiEEG.

## ¿Por qué importa?

El Octopus 16 es importante porque abre nuevas posibilidades para la interacción humo-computadora. Permite a los usuarios jugar juegos sin necesidad de manos o implantes, lo que puede ser beneficioso para personas con discapacidades físicas. Además, el dispositivo es compacto y fácil de usar, lo que lo hace accesible a un amplio rango de usuarios.

## Consejo técnico

Para empezar a utilizar el Octopus 16, es recomendable descargar el software de código abierto de GitHub y seguir las instrucciones de la documentación de PiEEG. También es importante asegurarse de que la placa de desarrollo XIAO ESP32-S3 o XIAO ESP32-C6 esté correctamente conectada y configurada.

```bash
git clone https://github.com/pi-eeg/octopus16
```

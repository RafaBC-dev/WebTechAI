## Introducción

Adafruit ha lanzado varios productos y proyectos interesantes en julio 2026, destacándose la producción en masa del ESP32-S31 y la creación de sistemas de automatización asequibles

## ¿Qué es?

El ESP32-S31 es un microcontrolador de 32 bits basado en el procesador ESP32, diseñado para aplicaciones de IoT y automatización. El ESP32-S3 SuperMini es una versión más pequeña y económica del microcontrolador, ideal para proyectos de prototipado y desarrollo.

## ¿Cómo funciona?

El ESP32-S31 y el ESP32-S3 SuperMini pueden ser utilizados para crear sistemas de automatización y control de dispositivos electrónicos. Pueden ser programados utilizando la plataforma ESPHome y la biblioteca Arduino. También se pueden utilizar para crear sistemas de monitoreo y control de temperatura, humedad y otros parámetros.

## ¿Por qué importa?

Estos productos importan porque ofrecen una solución asequible y fácil de usar para crear sistemas de automatización y control de dispositivos electrónicos. Pueden ser utilizados en una variedad de aplicaciones, desde la automatización de hogares hasta la creación de sistemas de monitoreo y control de procesos industriales.

## Consejo técnico

Si estás interesado en crear un sistema de automatización utilizando el ESP32-S31 o el ESP32-S3 SuperMini, considera utilizar la plataforma ESPHome y la biblioteca Arduino para programar y configurar tus dispositivos.

```bash
esp32-s31
```

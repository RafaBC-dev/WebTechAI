# BG2B: el procesador Bluetooth LE más bajo en consumo de Silicon Labs

**Fecha:** 2026-08-04
**Categoría:** embebidos
**Tags:** robotica, microcontroladores, embebidos
**Título original:** BG2B is the lowest-power Bluetooth LE SoC from Silicon Labs so far

---

## Introducción

Silicon Labs ha lanzado el BG2B, un procesador Bluetooth LE ultra bajo en consumo que busca revolucionar la tecnología IoT. Con un consumo de solo 1.1 µA en modo de sueño, este procesador es ideal para dispositivos que necesitan durar mucho tiempo sin recargar.

## ¿Qué es?

El BG2B es un procesador de 32 bits basado en el núcleo Arm Cortex-M33, diseñado específicamente para aplicaciones de Bluetooth LE. Ofrece una velocidad de reloj de 80 MHz y un conjunto de instrucciones DSP y FPU. También cuenta con 64 kB o 128 kB de RAM y 1016 kB de almacenamiento flash.

## ¿Cómo funciona?

El BG2B utiliza la tecnología Bluetooth LE 6 y cuenta con soporte para Channel Sounding, una característica que permite medir la distancia entre dispositivos. También incluye un conjunto de periféricos como LED drivers, ADCs y un controlador DMA de 8 canales. Además, cuenta con un sistema de seguridad robusto, incluyendo Secure Vault High y un generador de números aleatorios true.

## ¿Por qué importa?

El BG2B es importante porque ofrece una solución de bajo consumo para dispositivos IoT que necesitan durar mucho tiempo sin recargar. Es ideal para aplicaciones como seguimiento de activos, etiquetas de estantería electrónica, monitoreo industrial y diagnóstico de vehículos.

## Consejo técnico

Si estás diseñando un dispositivo IoT que requiere una larga duración de batería, considera utilizar el BG2B y aprovechar su bajo consumo y conjunto de periféricos avanzados.

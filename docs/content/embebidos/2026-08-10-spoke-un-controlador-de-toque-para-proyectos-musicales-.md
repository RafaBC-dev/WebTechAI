# SPOKE: un controlador de toque para proyectos musicales y más

**Fecha:** 2026-08-10
**Categoría:** embebidos
**Tags:** robotica, microcontroladores, software y linux
**Título original:** SPOKE: An RP2040-powered touch controller

---

## Introducción

La empresa Pimoroni ha lanzado un dispositivo llamado SPOKE, un controlador de toque que se parece a un disco de música pero tiene una función mucho más interesante. Con 27 touch pads y un microcontrolador RP2040, el SPOKE puede ser utilizado para crear proyectos musicales y otros tipos de aplicaciones.

## ¿Qué es?

El SPOKE es un dispositivo de control de toque que se conecta a un ordenador y permite interactuar con él mediante 27 touch pads. Estos pads están conectados a pines GPIO y pueden ser utilizados para crear proyectos musicales, como un controlador MIDI, o para otros tipos de aplicaciones.

## ¿Cómo funciona?

El SPOKE utiliza un microcontrolador RP2040 y 27 touch pads para detectar la presión de los dedos y enviar señales a un ordenador. El dispositivo viene con un programa de CircuitPython preinstalado que permite utilizarlo como un controlador MIDI. También cuenta con dos puertos Qwiic / STEMMA QT para conectar sensores y otros componentes.

## ¿Por qué importa?

El SPOKE importa porque ofrece una forma sencilla de crear proyectos musicales y otros tipos de aplicaciones interactivas. Puede ser utilizado para crear controladores MIDI, visualizadores de audio, y otros tipos de proyectos. También es una herramienta útil para aprender sobre la programación y la electrónica.

## Consejo técnico

Si deseas utilizar el SPOKE como un controlador MIDI, asegúrate de descargar el programa de CircuitPython y configurarlo correctamente en el dispositivo. También puedes utilizar el SPOKE para crear proyectos de visualización de audio utilizando las herramientas de Pimoroni.

```bash
sudo pip3 install circuitpython
```

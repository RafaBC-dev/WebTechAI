# Nuevos microcontroladores RISC-V con Ethernet y USB 2.0 para IoT y AI

**Fecha:** 2026-08-13
**Categoría:** embebidos
**Tags:** robotica, embebidos, linux

## Introducción

WCH ha lanzado dos nuevos microcontroladores RISC-V, CH32V407 y CH32V467, que integran Ethernet y USB 2.0 para aplicaciones de IoT y AI en el borde. Estos microcontroladores ofrecen una velocidad de reloj de 200 MHz y una memoria de hasta 8 MB de PSRAM.

## ¿Qué es?

El CH32V407 y CH32V467 son microcontroladores RISC-V con un núcleo de 32 bits que operan a una velocidad de reloj de hasta 200 MHz. Incluyen un conjunto de instrucciones RVV-vector y una memoria de hasta 8 MB de PSRAM. Estos microcontroladores están diseñados para aplicaciones de IoT y AI en el borde.

## ¿Cómo funciona?

El CH32V407 y CH32V467 funcionan con un núcleo RISC-V que ejecuta instrucciones RVV-vector. La memoria de PSRAM se utiliza para almacenar datos y programas. El microcontrolador incluye un conjunto de periféricos, como Ethernet, USB 2.0, LCD-TFT Display Controller y más. Estos periféricos se pueden utilizar para conectar dispositivos externos y realizar operaciones de I/O.

## ¿Por qué importa?

Estos microcontroladores son importantes para aplicaciones de IoT y AI en el borde, ya que ofrecen una velocidad de reloj alta y una memoria de PSRAM grande. Esto permite a los desarrolladores crear sistemas más eficientes y escalables. Además, la integración de Ethernet y USB 2.0 facilita la conexión a redes y dispositivos externos.

## Consejo técnico

Si estás desarrollando un proyecto de IoT o AI en el borde, considera utilizar el CH32V407 o CH32V467 como microcontrolador principal. Estos microcontroladores ofrecen una buena relación calidad-precio y pueden ser utilizados con herramientas de desarrollo como el MounRiver IDE.

## Introducción

Adafruit presenta un proyecto de impresión 3D llamado Flexi Skeleton, un esqueleto articulado que se puede imprimir en un solo bloque y que se puede posicionar de diferentes maneras. Este proyecto es perfecto para decoraciones de Halloween o como un juguete para el escritorio.

## ¿Qué es?

Flexi Skeleton es un modelo de impresión 3D que se puede imprimir en un solo bloque utilizando la tecnología de impresión en lugar. El modelo cuenta con articulaciones que permiten que el esqueleto se mueva y se posicione de diferentes maneras. Puede ser utilizado como decoración para Halloween o como un juguete para el escritorio.

## ¿Cómo funciona?

Para imprimir el modelo, se puede utilizar un impresor 3D con tecnología de impresión en lugar. El modelo se puede imprimir en un solo bloque y no requiere ensamblaje. Las articulaciones del modelo están diseñadas para permitir que el esqueleto se mueva y se posicione de diferentes maneras.

## ¿Por qué importa?

Este proyecto es importante porque muestra la capacidad de la impresión 3D para crear objetos complejos y articulados de manera sencilla. También es un ejemplo de cómo la impresión 3D puede ser utilizada para crear decoraciones y juguetes interesantes.

## Consejo técnico

Si deseas imprimir un modelo similar, puedes utilizar la herramienta de diseño 3D Tinkercad para crear tus propios modelos de impresión 3D.

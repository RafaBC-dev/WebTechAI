# Nueva placa de desarrollo PICO-ADN2 para aplicaciones espaciosas

**Categoría:** embebidos
**Tags:** robotica, embebidos, linux

## Introducción

La empresa AAEON ha lanzado una nueva placa de desarrollo PICO-ADN2, diseñada para aplicaciones que requieren un tamaño reducido. Esta placa es ideal para transporte, señalización digital, automatización industrial y kioscos inteligentes.

## ¿Qué es?

La placa PICO-ADN2 es una placa de desarrollo Pico-ITX que utiliza el procesador Intel Alder Lake-N, específicamente el Intel N97 o el Core i3-N305. Ofrece hasta 16 GB de memoria LPDDR5, interfaces de vídeo como HDMI, LVDS y eDP, y conectividad de red Gigabit Ethernet.

## ¿Cómo funciona?

La placa PICO-ADN2 cuenta con un procesador Intel Alder Lake-N que ofrece hasta 3.6 GHz de velocidad y 6 MB de caché. También incluye una GPU Intel UHD Graphics con 24 EU o 32 EU, dependiendo del procesador utilizado. La placa ofrece varias opciones de conectividad, incluyendo HDMI, LVDS, eDP, Gigabit Ethernet y USB.

## ¿Por qué importa?

La placa PICO-ADN2 es importante porque ofrece una solución compacta y potente para aplicaciones que requieren un tamaño reducido. Es ideal para transporte, señalización digital, automatización industrial y kioscos inteligentes, donde el espacio es un factor crítico.

## Consejo técnico

Si deseas utilizar la placa PICO-ADN2 con Linux, puedes utilizar la distribución Ubuntu para aprovechar al máximo las características de la placa. Puedes descargar la imagen de Ubuntu desde el sitio web oficial y seguir las instrucciones para instalarla en la placa.

```bash
sudo apt-get update && sudo apt-get install -y ubuntu-desktop
```

# M8 Controller Box: expansión industrial para cámaras de visión AI OAK4

**Fecha:** 2026-07-30
**Categoría:** embebidos
**Tags:** robotica, automatizacion, linux
**Título original:** Luxonis M8 Controller Box adds industrial I/Os, CAN Bus, and relay control to OAK4 AI vision cameras

## Introducción

Luxonis ha presentado un prototipo de la M8 Controller Box, una expansión industrial para cámaras de visión AI OAK4 que permite conectar sensores, actuadores y equipo industrial a sistemas de visión y automatización.

## ¿Qué es?

La M8 Controller Box es una expansión industrial que se conecta a las cámaras de visión AI OAK4 a través de la interfaz M8. Ofrece GPIO, relés, CAN Bus, serial y USB conectividad, permitiendo a los sistemas OAK4 interactuar directamente con sensores, actuadores, PLCs, motores y otros equipo industrial.

## ¿Cómo funciona?

La M8 Controller Box utiliza un MCU Raspberry Pi RP2040 para controlar los diferentes puertos y interfaces. Los 16 GPIOs pueden ser utilizados para conectar sensores y actuadores, mientras que los 4 relés de 16A pueden controlar cargas eléctricas. La interfaz CAN Bus permite la comunicación con otros dispositivos CAN, y los puertos USB y serial permiten la conexión a otros dispositivos y sistemas.

## ¿Por qué importa?

La M8 Controller Box es importante porque permite a los sistemas de visión AI OAK4 interactuar con el mundo físico de manera más directa y efectiva. Esto abre nuevas posibilidades para aplicaciones de visión y automatización en industrias como la manufactura, la logística y la agricultura.

## Consejo técnico

Para aprovechar al máximo la M8 Controller Box, es recomendable utilizar la biblioteca de desarrollo de Luxonis para Python, que ofrece una interfaz fácil de usar para controlar los puertos y interfaces de la expansión.

```bash
pip install luxonis-python
```

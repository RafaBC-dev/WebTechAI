# ChronoWatch X2040: un reloj DIY con Raspberry Pi y firmware personalizado

**Fecha:** 2026-08-04
**Categoría:** embebidos
**Tags:** robotica, microcontroladores, software-y-linux
**Título original:** ChronoWatch X2040 – A DIY watch with off-the-shelf Raspberry Pi RP2040 round display, 3D printed case, and custom firmware

## Introducción

Vishal Soni ha creado el ChronoWatch X2040, un reloj DIY que combina una pantalla circular de 1,28 pulgadas con un MCU Raspberry Pi RP2040 y un firmware personalizado. Este proyecto es una excelente opción para aquellos que desean crear su propio reloj sin necesidad de diseñar un circuito impreso personalizado.

## ¿Qué es?

El ChronoWatch X2040 es un reloj DIY que utiliza una pantalla circular de 1,28 pulgadas con un MCU Raspberry Pi RP2040, un 3D impreso y un firmware personalizado. El proyecto incluye una batería de 3,7V y una pantalla táctil para controlar el reloj.

## ¿Cómo funciona?

El ChronoWatch X2040 funciona con el firmware personalizado de Vishal Soni, que replica las funciones de un reloj tradicional, incluyendo el tiempo, la fecha y la hora en formato 12 o 24 horas. El firmware también incluye características como el control de brillo, un temporizador y opciones de rotación de pantalla.

## ¿Por qué importa?

El ChronoWatch X2040 es importante porque ofrece una forma fácil y económica de crear un reloj personalizado sin necesidad de diseñar un circuito impreso personalizado. El proyecto también demuestra la capacidad de los usuarios para crear dispositivos innovadores con tecnologías existentes.

## Consejo técnico

Si deseas crear tu propio ChronoWatch X2040, asegúrate de descargar el firmware personalizado de GitHub y seguir las instrucciones de assemblaje y carga de firmware en Hackster.io.

```bash
git clone https://github.com/vishalsoni/ChronoWatch-X2040
```

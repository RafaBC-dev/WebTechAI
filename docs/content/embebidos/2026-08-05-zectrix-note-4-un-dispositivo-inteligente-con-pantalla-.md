# ZecTrix Note 4: un dispositivo inteligente con pantalla e-paper y voz

**Fecha:** 2026-08-05
**Categoría:** embebidos
**Tags:** esp32, robotica, linux
**Título original:** ZecTrix Note 4 – A 4.2-inch ESP32-S3 wireless e-paper display for voice tasks

---

## Introducción

La empresa china ZecTrix Lab ha presentado el ZecTrix Note 4, un dispositivo inteligente con pantalla e-paper y voz que permite realizar tareas de voz y mostrar información en una pantalla de 4,2 pulgadas. Este dispositivo es ideal para aquellos que buscan una herramienta de productividad y organización en un solo dispositivo.

## ¿Qué es?

El ZecTrix Note 4 es un dispositivo de voz inteligente basado en el SoC ESP32-S3 de Espressif Systems, que cuenta con una pantalla e-paper de 4,2 pulgadas y un micrófono integrado para realizar tareas de voz. También cuenta con conectividad Wi-Fi y Bluetooth, así como una batería recargable de 2.000mAh.

## ¿Cómo funciona?

El dispositivo utiliza el SoC ESP32-S3 para procesar las tareas de voz y mostrar la información en la pantalla e-paper. La pantalla soporta una resolución de 400x300 píxeles y cuenta con la capacidad de actualizarse de manera parcial, lo que reduce la carga en la batería. El dispositivo también cuenta con un reloj de tiempo real integrado y una tarjeta de expansión GPIO para permitir la conexión de sensores y actuadores adicionales.

## ¿Por qué importa?

El ZecTrix Note 4 es importante porque ofrece una herramienta de productividad y organización en un solo dispositivo. Puede mostrar recordatorios, notas, relojes, el tiempo del clima y más en una pantalla de fácil lectura. Además, su capacidad de realizar tareas de voz y su conectividad Wi-Fi y Bluetooth lo convierten en una herramienta versátil para aquellos que buscan una forma sencilla de acceder a la información.

## Consejo técnico

Si deseas utilizar el ZecTrix Note 4 como dispositivo de voz inteligente, puedes instalar el firmware de código abierto vibecoding-voice, que te permite utilizar el dispositivo como una herramienta de voz para herramientas de codificación como OpenAI Codex y Claude Code.

# LILYGO T-Display C5: una placa ESP32-C5 con pantalla y conectividad

## Introducción

LILYGO ha lanzado la placa T-Display C5, una placa ESP32-C5 con pantalla y conectividad que ofrece una solución completa para proyectos IoT. Esta placa es ideal para aplicaciones que requieren una pantalla y conectividad inalámbrica.

## ¿Qué es?

La placa T-Display C5 es una placa ESP32-C5 que incluye una pantalla de 1,9 pulgadas de resolución 172x320, conectividad dual-banda WiFi 6 y Bluetooth LE 5.x, y dos conectores Qwiic para expansiones adicionales. También incluye soporte para batería y un puerto USB-C para programación y alimentación.

## ¿Cómo funciona?

La placa T-Display C5 utiliza el procesador ESP32-C5HR8, que cuenta con un núcleo RISC-V de 32 bits a 240 MHz y un núcleo de bajo consumo a 40 MHz. La placa también incluye 384 KB de SRAM, 8 MB de PSRAM y 320 KB de ROM. La pantalla es controlada por el controlador ST7735 y se puede conectar a través de un conector SPI.

## ¿Por qué importa?

La placa T-Display C5 es importante porque ofrece una solución completa para proyectos IoT que requieren una pantalla y conectividad inalámbrica. Es ideal para aplicaciones como monitores de temperatura, sensores de movimiento y otros proyectos que requieren una pantalla y conectividad.

## Consejo técnico

Si deseas empezar a trabajar con la placa T-Display C5, te recomiendo descargar el firmware y los ejemplos de código de GitHub y utilizar la plataforma PlatformIO o el IDE de Arduino para programar la placa.

git clone https://github.com/LILYGO/LILYGO-T-Display-C5.git

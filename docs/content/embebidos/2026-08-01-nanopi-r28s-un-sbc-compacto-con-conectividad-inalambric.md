# NanoPi R28S: un SBC compacto con conectividad inalámbrica y Ethernet

**Fecha:** 2026-08-01
**Categoría:** embebidos
**Tags:** robotica, embebidos, linux
**Título original:** NanoPi R28S – A tiny dual GbE Rockchip RK3528A wireless SBC and router with a USB-C console port

## Introducción

FriendlyELEC ha lanzado el NanoPi R28S, un pequeño SBC (Single Board Computer) que combina conectividad inalámbrica y Ethernet, ideal para aplicaciones de red y IoT.

## ¿Qué es?

El NanoPi R28S es un SBC compacto que mide 49.5 x 49.5 x 24 mm y pesa 77.5 gramos. Está equipado con el procesador Rockchip RK3528A, que cuenta con una CPU quad-core ARM Cortex-A53 a 1.8 GHz y un GPU Mali-450. También cuenta con 1 GB de memoria LPDDR4 y una ranura para tarjeta microSD.

## ¿Cómo funciona?

El NanoPi R28S cuenta con dos puertos Ethernet Gigabit, WiFi 6 y Bluetooth 5.3. Los puertos USB-C se utilizan únicamente para alimentación, actualizaciones de firmware y depuración. El sistema no cuenta con puertos USB para conectividad de datos ni con una placa de expansión GPIO.

## ¿Por qué importa?

El NanoPi R28S es ideal para aplicaciones de red y IoT, como firewalls, routers y puertas de enlace. También puede ser utilizado como gateway de IoT. Su compacto tamaño y conectividad inalámbrica lo hacen una opción atractiva para proyectos de red y automatización.

## Consejo técnico

Si estás interesado en utilizar el NanoPi R28S como router, asegúrate de configurar el firmware FriendlyWrt 25.12, que es compatible con este SBC.

```bash
sudo apt-get install friendlywrt-25.12
```

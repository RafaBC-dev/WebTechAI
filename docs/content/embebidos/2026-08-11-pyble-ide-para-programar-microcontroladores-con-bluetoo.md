# PyBLE: IDE para programar microcontroladores con Bluetooth LE

## Introducción

PyBLE es un IDE open-source que permite programar microcontroladores con Bluetooth Low Energy (BLE) desde tabletas y iPads. Este proyecto es relevante para desarrolladores que buscan una forma sencilla de programar y controlar dispositivos IoT.

## ¿Qué es?

PyBLE es un entorno de desarrollo integrado (IDE) open-source que se enfoca en programar microcontroladores con Bluetooth Low Energy (BLE). Combina una interfaz de usuario basada en Flutter con soporte para MicroPython y programación visual (Blockly).

## ¿Cómo funciona?

PyBLE funciona mediante una aplicación móvil que se conecta a un firmware de MicroPython en el microcontrolador. El firmware expone una interfaz BLE que permite la comunicación con la aplicación móvil. La aplicación móvil proporciona una interfaz de usuario para editar y ejecutar código, así como para gestionar archivos y configurar el dispositivo.

## ¿Por qué importa?

PyBLE es importante porque ofrece una forma sencilla y accesible para programar y controlar dispositivos IoT con Bluetooth LE. Esto abre nuevas posibilidades para proyectos de IoT y educación en robótica.

## Consejo técnico

Si deseas empezar a utilizar PyBLE, asegúrate de instalar el firmware correcto para tu microcontrolador y de configurar la aplicación móvil para conectarse al dispositivo.

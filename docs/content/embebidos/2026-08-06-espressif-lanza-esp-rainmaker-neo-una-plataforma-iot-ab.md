# Espressif lanza ESP RainMaker Neo, una plataforma IoT abierta y personalizable

**Fecha:** 2026-08-06
**Categoría:** embebidos
**Tags:** robotica, embebidos, linux
**Título original:** Espressif Systems releases ESP RainMaker Neo open-source device-to-cloud-to-phone IoT platform

---

## Introducción

Espressif Systems ha lanzado ESP RainMaker Neo, una plataforma IoT completa que permite la integración de dispositivos, nubes y aplicaciones móviles. Esta plataforma es la versión abierta de la plataforma ESP RainMaker, que ya existía desde 2020. Con ESP RainMaker Neo, los desarrolladores tienen más flexibilidad y control sobre la arquitectura de la nube.

## ¿Qué es?

ESP RainMaker Neo es una plataforma IoT abierta que incluye un backend de nube, un SDK de firmware, ejemplos de firmware, un SDK de aplicación móvil y una aplicación de referencia. Esta plataforma se basa en la arquitectura de servidorless de AWS y está disponible bajo la licencia Apache 2.0. El código fuente y los recursos para empezar están disponibles en cuatro repositorios de GitHub.

## ¿Cómo funciona?

La plataforma ESP RainMaker Neo se compone de cuatro componentes principales: el backend de nube, el SDK de firmware, el SDK de aplicación móvil y la aplicación de referencia. El backend de nube se ejecuta en la nube y gestiona la integración de dispositivos y aplicaciones. El SDK de firmware proporciona una API para desarrollar firmware para dispositivos IoT. El SDK de aplicación móvil permite desarrollar aplicaciones móviles que interactúen con la plataforma. La aplicación de referencia es un ejemplo de cómo utilizar la plataforma.

## ¿Por qué importa?

ESP RainMaker Neo importa porque ofrece una plataforma IoT abierta y personalizable que permite a los desarrolladores crear soluciones IoT customizadas. Esta plataforma es ideal para proyectos de IoT que requieren una gran flexibilidad y control sobre la arquitectura de la nube.

## Consejo técnico

Si deseas empezar a utilizar ESP RainMaker Neo, puedes seguir los pasos para una implementación rápida en la documentación oficial. También puedes consultar la documentación de AWS para obtener más información sobre la arquitectura de servidorless.

## Introducción

Makerfabs ha lanzado el MaTouch ESP32-S3 MaUWB, un desarrollo de placa que combina un módulo de MCU inalámbrico ESP32-S3, una pantalla táctil de 3.95 pulgadas y un módulo UWB para aplicaciones de posicionamiento indoor y rango.

## ¿Qué es?

El MaTouch ESP32-S3 MaUWB es un desarrollo de placa que integra un módulo de MCU inalámbrico ESP32-S3, una pantalla táctil de 3.95 pulgadas y un módulo UWB. Este desarrollo se puede utilizar como terminal de posicionamiento portátil. Utiliza un algoritmo de trilateración con hasta tres anclajes UWB fijos para calcular las coordenadas del tag en tiempo real.

## ¿Cómo funciona?

El MaTouch ESP32-S3 MaUWB utiliza un algoritmo de trilateración para calcular las coordenadas del tag en tiempo real. El módulo UWB opera en el canal 5 de UWB (6489,6 MHz) y admite hasta 8 anclajes y 64 tags. La placa incluye un conector de batería LiPo, un circuito de carga y un monitor de nivel de batería.

## ¿Por qué importa?

El MaTouch ESP32-S3 MaUWB es relevante para proyectos de posicionamiento indoor y rango, ya que ofrece una solución portátil y fácil de usar. Puede ser utilizado en aplicaciones como la gestión de inventarios, la monitorización de edificios y la seguridad.

# NanoPi R28S: un pequeño SBC con Wi-Fi 6 y Ethernet dual Gigabit

## Introducción

FriendlyELEC ha lanzado el NanoPi R28S, un pequeño SBC (Single Board Computer) con Wi-Fi 6 y Ethernet dual Gigabit, diseñado para aplicaciones de red y IoT. Este dispositivo es ideal para firewalls, routers y puertas de enlace IoT.

## ¿Qué es?

El NanoPi R28S es un SBC de tamaño reducido que utiliza el procesador Rockchip RK3528A, con un cuad-core ARM Cortex-A53 a 1.8 GHz. Cuenta con 1 GB de memoria LPDDR4, una ranura para tarjeta microSD y un conector eMMC para almacenamiento. También incluye Wi-Fi 6 y Bluetooth 5.3, así como dos puertos Ethernet Gigabit.

## ¿Cómo funciona?

El SBC utiliza el procesador Rockchip RK3528A, que incluye un cuad-core ARM Cortex-A53 a 1.8 GHz, un GPU Mali-450 y un VPU para decodificar vídeo 4K. La memoria LPDDR4 de 1 GB permite ejecutar aplicaciones de red y IoT de manera eficiente. El Wi-Fi 6 y Bluetooth 5.3 permiten una conexión estable y segura a la red.

## ¿Por qué importa?

El NanoPi R28S es importante porque ofrece una solución compacta y eficiente para aplicaciones de red y IoT. Puede ser utilizado como firewall, router o puerta de enlace IoT, lo que lo hace ideal para proyectos de red y automatización.

## Consejo técnico

Si deseas utilizar el NanoPi R28S como firewall o router, asegúrate de configurar correctamente la red y los puertos de seguridad para evitar vulnerabilidades.

```bash
apt-get update && apt-get install -y u-boot-rockchip
```

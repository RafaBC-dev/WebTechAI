# Nueva placa de sensores para robots con conectividad GMSL y CAN-FD

**Fecha:** 2026-08-03
**Categoría:** embebidos
**Tags:** robotica, embebidos, linux
**Título original:** Aliensense NXS is a plug-and-play GMSL 2/3 and CAN-FD sensor board for robots

## Introducción

La empresa Aliensense ha lanzado una nueva placa de sensores llamada NXS, diseñada para conectar cámaras y sensores a robots de manera fácil y rápida. Esta placa utiliza un cable GMSL 2/3 para transmitir datos y video a través de hasta 15 metros, lo que la hace ideal para aplicaciones de robotica y automatización.

## ¿Qué es?

La placa NXS es un dispositivo compacto que permite conectar cámaras y sensores a robots sin necesidad de cableado personalizado o trabajo de drivers. Utiliza un MCU STM32G491 y cuenta con una interfaz de cámara MIPI CSI-2, un serializer GMSL2/3 y conectividad CAN-FD.

## ¿Cómo funciona?

La placa NXS funciona conectando un cable GMSL 2/3 a una cámara o sensor, lo que permite transmitir datos y video a través de hasta 15 metros. También cuenta con una mikroBUS socket que permite conectar módulos de sensores adicionales, como un IMU 6DOF. La placa utiliza un software de open-source para sincronizar sensores y cámaras en tiempo real.

## ¿Por qué importa?

La placa NXS es importante porque resuelve problemas de conectividad y sincronización en aplicaciones de robotica y automatización. También permite a los desarrolladores crear sistemas de robotica más complejos y precisos sin necesidad de cableado personalizado.

## Consejo técnico

Si estás desarrollando un proyecto de robotica, considera utilizar la placa NXS para conectar tus cámaras y sensores de manera fácil y rápida. Puedes conectar módulos de sensores adicionales a través de la mikroBUS socket y sincronizarlos en tiempo real utilizando software de open-source.

```bash
nxs command line utility
```

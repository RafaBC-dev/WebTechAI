# PiShot: una cámara compacta y portátil para Raspberry Pi

**Fecha:** 2026-08-11
**Categoría:** embebidos
**Tags:** robotica, microcontroladores, software-y-linux
**Título original:** The PiShot Is Ready For Your Snaps

---

## Introducción

La Raspberry Pi ha revolucionado la creación de cámaras compactas y portátiles. El PiShot es la última adición a esta familia de dispositivos, ofreciendo una cámara de alta calidad y una pantalla en un solo dispositivo.

## ¿Qué es?

El PiShot es un dispositivo de cámara compacto y portátil basado en Raspberry Pi, que combina una cámara de alta calidad con una pantalla y un sistema de batería. Utiliza un Raspberry Pi Zero 2 W y una cámara de módulo 3, con un panel de batería de 18650 y un circuito de gestión de energía.

## ¿Cómo funciona?

El PiShot utiliza una cámara de módulo 3 y un Raspberry Pi Zero 2 W, que se controla mediante un script de Python. La pantalla se conecta mediante un cable SPI y las teclas táctiles se conectan a los GPIO del Pi. El dispositivo se alimenta mediante una batería de 18650 y un circuito de gestión de energía.

## ¿Por qué importa?

El PiShot es importante porque ofrece una cámara de alta calidad y una pantalla en un solo dispositivo, lo que lo hace ideal para aplicaciones de captura de imágenes y videos en el campo, como la fotografía de paisajes o la grabación de eventos.

## Consejo técnico

Si deseas mejorar la calidad de la cámara del PiShot, considera utilizar un módulo de cámara de alta calidad, como el HQ Camera Module, que ofrece una resolución de hasta 16 megapíxeles.

```bash
python pi_shot.py
```

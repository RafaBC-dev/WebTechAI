## Introducción

El SPOKE es un dispositivo que parece un disco de música de los años 90, pero en realidad es un controlador táctil con 27 pines GPIO y un microcontrolador RP2040. Puedes conectarlo a tu computadora y usarlo como controlador MIDI para tocar notas musicales.

## ¿Qué es?

El SPOKE es un dispositivo que combina un microcontrolador RP2040 con 27 pines GPIO que funcionan como sensores táctiles. Cada pín se puede asignar a una nota musical específica, lo que lo convierte en un controlador MIDI completo.

## ¿Cómo funciona?

El SPOKE utiliza el microcontrolador RP2040 para leer los cambios en la carga eléctrica de los 27 pines GPIO, que se utilizan como sensores táctiles. Cuando se toca un pín, se genera una señal que se envía a la computadora, que la interpreta como una nota musical. El dispositivo también tiene dos puertos Qwiic/STEMMA QT para conectar sensores y componentes adicionales.

## ¿Por qué importa?

El SPOKE es importante porque ofrece una forma sencilla y divertida de crear música y experimentar con el controlador MIDI. Puedes usarlo para tocar notas musicales, crear patrones de sonido y explorar la programación de microcontroladores.

## Consejo técnico

Puedes extender los sensores táctiles del SPOKE utilizando materiales conductivos como cinta de cobre, hilo conductivo o tinta conductiva. Experimenta con diferentes materiales y diseños para crear un controlador táctil personalizado.

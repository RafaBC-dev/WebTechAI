# Makerfabs Nomad Terminal: una plataforma de desarrollo portátil con tecnología LoRa

## Introducción

Makerfabs ha lanzado la Nomad Terminal, una plataforma de desarrollo portátil que combina tecnología LoRa con un procesador ESP32-S3 y un módulo GNSS. Esta herramienta es ideal para aplicaciones que requieren comunicación inalámbrica de larga distancia sin conexión celular.

## ¿Qué es?

La Nomad Terminal es una plataforma de desarrollo portátil que se basa en el procesador ESP32-S3 y el módulo LoRa LR1121 de Semtech. También cuenta con un módulo GNSS ATGM336H y un display táctil de 3,5 pulgadas. Esta plataforma es diseñada para aplicaciones que requieren comunicación inalámbrica de larga distancia sin conexión celular, como mensajería LoRa, seguimiento de GPS, navegación y monitoreo de sensores.

## ¿Cómo funciona?

La Nomad Terminal utiliza el procesador ESP32-S3 para ejecutar el software y el módulo LoRa LR1121 para comunicarse con otros dispositivos a larga distancia. El módulo GNSS ATGM336H proporciona ubicación y tiempo precisos. El display táctil de 3,5 pulgadas permite interactuar con la plataforma y visualizar información en tiempo real.

## ¿Por qué importa?

La Nomad Terminal es importante porque ofrece una solución para aplicaciones que requieren comunicación inalámbrica de larga distancia sin conexión celular. Esto es especialmente útil en áreas rurales o remotas donde la conectividad celular es limitada. Además, la plataforma es compatible con tecnologías como Meshtastic y MeshCore, lo que la hace una opción atractiva para proyectos de IoT y comunicación inalámbrica.

## Consejo técnico

Si estás interesado en desarrollar aplicaciones con la Nomad Terminal, te recomendamos utilizar la biblioteca RadioLib para comunicarte con el módulo LoRa y la biblioteca TinyGPSPlus para obtener datos de ubicación y tiempo precisos. También es importante mencionar que la plataforma utiliza el framework LVGL para la interfaz gráfica.

```bash
git clone https://github.com/Makerfabs/Nomad-Terminal.git
```

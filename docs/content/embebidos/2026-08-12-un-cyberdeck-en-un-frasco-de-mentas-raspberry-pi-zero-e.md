# Un cyberdeck en un frasco de mentas: Raspberry Pi Zero en un Altoids

**Fecha:** 2026-08-12
**Categoría:** embebidos
**Tags:** robotica, diseño-3d, electronica
**Título original:** Curiously minty Raspberry Pi Zero cyberdeck

## Introducción

La comunidad de Raspberry Pi sigue innovando con proyectos sorprendentes, como este cyberdeck miniatura que combina electrónica y diseño 3D.

## ¿Qué es?

Un cyberdeck es un dispositivo portátil que combina una computadora con un teclado y una pantalla para crear una experiencia de usuario inmersiva. En este caso, se ha construido un cyberdeck en un frasco de mentas Altoids utilizando un Raspberry Pi Zero, un teclado personalizado y una pantalla LCD de 2 pulgadas.

## ¿Cómo funciona?

El proyecto utiliza un Raspberry Pi Zero como procesador principal, conectado a un teclado personalizado hecho con un protoboard y un microcontrolador Waveshare RP2040 Zero. La pantalla LCD se conecta directamente al Raspberry Pi Zero, y se utiliza un UPS HAT y una batería para proporcionar energía al dispositivo. El diseño 3D se utiliza para crear un soporte flexible que se ajusta al frasco de mentas.

## ¿Por qué importa?

Este proyecto es importante porque demuestra la posibilidad de crear dispositivos portátiles y autónomos utilizando tecnología de código abierto y diseño 3D. También muestra la creatividad y la innovación que se pueden lograr al combinar diferentes tecnologías y componentes.

## Consejo técnico

Si deseas crear un proyecto similar, considera utilizar un diseño 3D flexible para crear un soporte que se ajuste a tu dispositivo. También puedes utilizar un microcontrolador como el Waveshare RP2040 Zero para crear un teclado personalizado.

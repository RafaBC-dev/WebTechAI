# SPOKE: un controlador de toque basado en RP2040

**Fecha:** 2026-08-13
**Categoría:** embebidos
**Tags:** robotica, microcontroladores, software y linux
**Título original:** SPOKE: An RP2040-powered touch controller

## Introducción

El SPOKE es un dispositivo innovador que combina tecnología de toque capacitivo con un microcontrolador RP2040. Puede ser utilizado como controlador MIDI y ofrece una variedad de opciones para proyectos musicales y de toque.

## ¿Qué es?

El SPOKE es un dispositivo de toque capacitivo que cuenta con 27 pines GPIO y un microcontrolador RP2040. Cada uno de los 27 pines está conectado a un touch pad capacitivo, lo que permite una gran variedad de posibilidades para proyectos de toque y música.

## ¿Cómo funciona?

El SPOKE funciona conectando el dispositivo a un ordenador y configurando el software en el sitio web spokeboard.com. El dispositivo se convierte en un controlador MIDI, permitiendo que cada touch pad se asigne a una nota musical. El dispositivo también cuenta con puertos Qwiic y STEMMA QT para conectar sensores y otros componentes.

## ¿Por qué importa?

El SPOKE importa porque ofrece una forma innovadora de interactuar con la música y los proyectos de toque. Puede ser utilizado para proyectos musicales, como la creación de melodías y la generación de efectos de sonido, y también para proyectos de toque, como la creación de interfaces de usuario interactivas.

## Consejo técnico

Si deseas utilizar el SPOKE como controlador MIDI, asegúrate de visitar el sitio web spokeboard.com y configurar el software correctamente. También puedes utilizar el SPOKE para crear proyectos de toque capacitivo extendiendo los touch pads con materiales conductivos, como cinta de cobre o hilo conductivo.

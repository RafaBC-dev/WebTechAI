# Nueva pantalla táctil de 10 pulgadas para Raspberry Pi, a $80

**Fecha:** 2026-07-25

**Título original:** A new 10″ Raspberry Pi Touch Display 2, available now at $80

## Introducción

La Raspberry Pi ha lanzado una nueva pantalla táctil de 10 pulgadas para sus dispositivos, con una resolución más alta y un ángulo de visión más amplio. Esta pantalla es ideal para aplicaciones de automación, kioscos y sistemas de control de laboratorio.

## ¿Qué es?

La nueva pantalla táctil de 10 pulgadas para Raspberry Pi es una pantalla táctil capacitiva con una resolución de 1200x1920 píxeles y un ángulo de visión de 85 grados. Se integra fácilmente con el resto del ecosistema de Raspberry Pi y viene con todos los cables y conectores necesarios.

## ¿Cómo funciona?

La pantalla se conecta directamente al Raspberry Pi y utiliza el controlador de pantalla táctil integrado en el sistema operativo Raspberry Pi OS. No es necesaria ninguna calibración manual y se puede conectar a cualquier modelo de Raspberry Pi 5 o Compute Module con una placa de expansión adecuada.

## ¿Por qué importa?

Esta pantalla es ideal para aplicaciones de automación, kioscos y sistemas de control de laboratorio, ya que ofrece una resolución más alta y un ángulo de visión más amplio. También es compatible con el resto del ecosistema de Raspberry Pi, lo que la hace fácil de integrar en proyectos existentes.

## Consejo técnico

Si estás planeando utilizar la pantalla táctil de 10 pulgadas con un Raspberry Pi 5 o Compute Module, asegúrate de utilizar la placa de expansión adecuada y de configurar correctamente el controlador de pantalla táctil en el sistema operativo.

```bash
raspi-config --expand-rootfs
```

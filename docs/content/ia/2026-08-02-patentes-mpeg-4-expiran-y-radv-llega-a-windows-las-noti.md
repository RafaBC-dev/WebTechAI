## Introducción

El mes de julio ha sido emocionante para la comunidad de Linux y código abierto. La última patente de MPEG-4 ha expirado, RADV llega a Windows y se han anunciado varias noticias interesantes sobre Linux y hardware.

## ¿Qué es?

MPEG-4 es un estándar de codificación de video que ha sido ampliamente utilizado en la industria del entretenimiento. La expiración de la última patente de MPEG-4 significa que cualquier persona puede utilizar este estándar sin tener que pagar licencias. RADV es una implementación de la API de gráficos Vulkan para Linux que ahora está disponible en Windows.

## ¿Cómo funciona?

La expiración de la patente de MPEG-4 permite a los desarrolladores utilizar este estándar sin restricciones. RADV, por otro lado, es una implementación de la API de gráficos Vulkan que permite a los desarrolladores crear aplicaciones gráficas en Linux que sean compatibles con Windows. La implementación de RADV en Windows permite a los usuarios de Windows disfrutar de aplicaciones gráficas en Linux.

## ¿Por qué importa?

La expiración de la patente de MPEG-4 es importante porque permite a los desarrolladores utilizar este estándar sin restricciones, lo que puede llevar a la creación de nuevas aplicaciones y servicios. La implementación de RADV en Windows es importante porque permite a los usuarios de Windows disfrutar de aplicaciones gráficas en Linux, lo que puede mejorar la experiencia del usuario.

## Consejo técnico

Si deseas utilizar RADV en Windows, puedes descargar la última versión de RADV desde el sitio web de Phoronix y seguir las instrucciones de instalación.

```bash
sudo apt-get install radv
```

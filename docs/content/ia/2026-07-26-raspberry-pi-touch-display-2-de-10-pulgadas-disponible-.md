## Introducción

La Raspberry Pi ha lanzado un nuevo display táctil de 10 pulgadas, con una resolución más alta y un ángulo de visión más amplio. Este dispositivo es perfecto para aplicaciones como dashboards, kiosks y sistemas de control de robots.

## ¿Qué es?

El Raspberry Pi Touch Display 2 de 10 pulgadas es un dispositivo de pantalla táctil que se conecta a un Raspberry Pi para crear una interfaz de usuario interactiva. Tiene una resolución de 1200x1920 píxeles y un ángulo de visión de 85 grados.

## ¿Cómo funciona?

El display se conecta directamente a un Raspberry Pi 5 o a un Compute Module, y viene con todos los cables y hardware necesarios. La pantalla táctil cuenta con soporte para 10 dedos y no requiere calibración manual. El dispositivo utiliza cuatro canales de DSI para comunicarse con el host Raspberry Pi.

## ¿Por qué importa?

Este display es ideal para aplicaciones que requieren una interfaz de usuario interactiva, como dashboards de automatización doméstica, kiosks, sistemas de control de robots y paneles de control de laboratorios.

## Consejo técnico

Si deseas utilizar este display con un Raspberry Pi 4 o anterior, considera utilizar el display de 5 o 7 pulgadas, que son compatibles con estos modelos.

```bash
sudo apt-get install raspbian
```

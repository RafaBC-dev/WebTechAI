# Raspberry Pi lanza pantalla táctil de 10 pulgadas a 80 dólares

**Fecha:** 2026-08-02
**Categoría:** ia
**Tags:** robotica, raspberry-pi, linux
**Título original:** A new 10″ Raspberry Pi Touch Display 2, available now at $80

---

## Introducción

Raspberry Pi ha lanzado una nueva pantalla táctil de 10 pulgadas, una actualización de su pantalla táctil de 7 pulgadas. Esta nueva pantalla ofrece una resolución más alta y un ángulo de visión más amplio, lo que la hace ideal para aplicaciones como kioscos, interfaces de robots y paneles de control.

## ¿Qué es?

La pantalla táctil de 10 pulgadas de Raspberry Pi es una pantalla táctil capacitiva con una resolución de 1200x1920 píxeles, un ángulo de visión de 85 grados y soporte para 10 dedos de tacto. Se conecta directamente al Raspberry Pi y viene con todos los cables y hardware necesarios.

## ¿Cómo funciona?

La pantalla se conecta al Raspberry Pi a través de un cable DSI de 4 canales, que permite una transferencia de datos más rápida y eficiente. El software de Raspberry Pi OS proporciona soporte completo para la pantalla, lo que permite una configuración fácil y rápida.

## ¿Por qué importa?

Esta pantalla es ideal para aplicaciones que requieren una interfaz táctil, como kioscos, interfaces de robots, paneles de control y sistemas de señalización digital. También es compatible con el Raspberry Pi 5 y el Compute Module, lo que la hace una opción atractiva para desarrolladores y proyectos de IoT.

## Consejo técnico

Si deseas conectar la pantalla a tu Raspberry Pi, asegúrate de actualizar el software de Raspberry Pi OS y EEPROM bootloader para obtener soporte completo para la pantalla.

```bash
sudo apt-get update && sudo apt-get install raspbian
```

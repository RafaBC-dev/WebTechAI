# ASUS UGen300: acelerador USB AI para modelos de lenguaje y visión

**Fecha:** 2026-08-03
**Categoría:** ia
**Tags:** ia-local, llms, linux

## Introducción

ASUS ha lanzado el UGen300, un acelerador USB AI que combina un procesador Hailo-10H con 8GB de memoria LPDDR4 para acelerar modelos de lenguaje y visión. Este dispositivo es ideal para aplicaciones de IA que requieren procesamiento de imágenes y texto.

## ¿Qué es?

El ASUS UGen300 es un acelerador USB AI que se conecta a un host x86 o Arm mediante un puerto USB-C de 10 Gbps. Contiene un procesador Hailo-10H que puede alcanzar hasta 40 TOPS de rendimiento de inferencia, así como 8GB de memoria LPDDR4 para almacenar modelos de lenguaje y visión.

## ¿Cómo funciona?

El UGen300 utiliza el procesador Hailo-10H para acelerar la inferencia de modelos de lenguaje y visión. La memoria LPDDR4 se utiliza para almacenar los modelos y los datos de entrada. El dispositivo es fanless y cuenta con un gran enfriador interno que mantiene la temperatura del procesador bajo control.

## ¿Por qué importa?

El UGen300 es importante porque permite a los desarrolladores acelerar la inferencia de modelos de lenguaje y visión en aplicaciones de IA. Esto puede mejorar la velocidad y la eficiencia de las aplicaciones, especialmente en dispositivos con recursos limitados.

## Consejo técnico

Si estás desarrollando aplicaciones de IA que requieren procesamiento de imágenes y texto, considera utilizar el UGen300 como acelerador. Puedes instalar el SDK de HailoRT en Ubuntu y utilizar Python para crear aplicaciones que utilicen el UGen300.

```bash
sudo apt-get install libhailort-dev
```

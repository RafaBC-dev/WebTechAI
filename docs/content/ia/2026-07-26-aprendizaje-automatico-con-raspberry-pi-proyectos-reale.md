## Introducción

La inteligencia artificial no solo se encuentra en centros de datos gigantes, sino también en una computadora de placa única como la Raspberry Pi, que puede ejecutar modelos de aprendizaje automático localmente, de manera segura y privada.

## ¿Qué es?

El libro 'AI Projects with Raspberry Pi' es una guía práctica para descubrir aplicaciones de aprendizaje automático en la vida real con hardware de Raspberry Pi. Los proyectos no son demostraciones de juguete, sino proyectos que se pueden construir, ejecutar y decir: 'Lo hice yo'.

## ¿Cómo funciona?

El libro cubre una amplia gama de aplicaciones de aprendizaje automático, todas ellas ejecutadas en una Raspberry Pi, incluyendo visión por computadora, modelado predictivo con Python, reconocimiento de voz y texto, procesamiento de lenguaje natural, sensor data y modelos de lenguaje grande.

## ¿Por qué importa?

Esto importa porque permite a los usuarios ejecutar modelos de aprendizaje automático de manera local, segura y privada, lo que es especialmente útil en aplicaciones de IoT y sensores.

## Consejo técnico

Utiliza la biblioteca OpenCV para implementar visión por computadora con Raspberry Pi y Python.

```bash
pip install opencv-python
```

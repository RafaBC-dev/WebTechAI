# Cloudflare lanza Kitesurf, un navegador para agentes de IA

**Fecha:** 2026-08-08
**Categoría:** ia
**Tags:** ia-local, agentes, linux
**Título original:** Cloudflare launches Kitesurf, a browser built for AI agents

---

## Introducción

Cloudflare ha lanzado Kitesurf, un navegador diseñado específicamente para agentes de IA. Este navegador es crucial para la transición de los chatbots a agentes que pueden completar tareas en nombre de los usuarios.

## ¿Qué es?

Kitesurf es un navegador en la nube diseñado para agentes de IA. No necesita gestión de ventanas visuales, como temas o extensiones, y se enfoca en la gestión de ventanas de contexto, rendimiento, costos de tokens y escalabilidad.

## ¿Cómo funciona?

Kitesurf se construyó utilizando una plataforma serverless de Cloudflare llamada Workers. Incorpora un motor de renderizado modular de Blitz, un parser de CSS de Stylo y un motor de ECMAScript de Boa JS. También utiliza la tecnología Obscura para inspirarse en la creación de un motor de renderizado en cabeza.

## ¿Por qué importa?

Kitesurf permite a los desarrolladores de IA crear software que pueda navegar por sitios web, rellenar formularios y completar otras tareas basadas en el navegador, sin tener que construir su propio software de navegador. Esto reduce los costos de computación y mejora la eficiencia de los agentes de IA.

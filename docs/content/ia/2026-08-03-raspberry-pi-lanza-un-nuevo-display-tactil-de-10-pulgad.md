# Raspberry Pi lanza un nuevo display táctil de 10 pulgadas

**Fecha:** 2026-08-03
**Categoría:** ia
**Tags:** robotica, raspberry-pi, linux
**Título original:** A new 10″ Raspberry Pi Touch Display 2, available now at $80

---

## Introducción

La empresa Raspberry Pi ha lanzado un nuevo display táctil de 10 pulgadas, que ofrece una resolución más alta y un ángulo de visión más amplio que sus predecesores. Este dispositivo es perfecto para aplicaciones como la automatización de hogares, kioscos, interfaces de robots y más.

## ¿Qué es?

El Raspberry Pi Touch Display 2 de 10 pulgadas es un dispositivo de pantalla táctil que se conecta directamente a un Raspberry Pi. Ofrece una resolución de 1200x1920 píxeles, un ángulo de visión de 85 grados y soporte para diez dedos de tacto.

## ¿Cómo funciona?

El display se conecta a un Raspberry Pi 5 o un Compute Module mediante un cable de 4 líneas de DSI. El sistema operativo Raspberry Pi OS proporciona soporte completo para el display, lo que hace que sea fácil de configurar y utilizar.

## ¿Por qué importa?

Este display es ideal para aplicaciones que requieren una pantalla táctil grande y alta resolución, como la automatización de hogares, kioscos, interfaces de robots y más. También es perfecto para proyectos de IoT y de inteligencia artificial.

## Consejo técnico

Si deseas utilizar el display con un Raspberry Pi 4 o anterior, te recomendamos considerar la opción de utilizar el display de 5 o 7 pulgadas, que son compatibles con estos modelos.

```bash
sudo apt-get update && sudo apt-get install raspbian
```

## Introducción

La creación de sistemas de inteligencia física puede ser un proceso complejo, ya que implica la integración de herramientas fragmentadas para datos, entrenamiento, simulación y control de hardware. CYCLO es una plataforma abierta y modular diseñada para conectar todo el flujo de trabajo de inteligencia física en un solo flujo.

## ¿Qué es?

CYCLO es una plataforma de software abierta y modular que permite la creación y operación de sistemas de inteligencia física. Combina herramientas para la recopilación de datos, entrenamiento de políticas de aprendizaje automático, control de movimiento y simulación. Tiene una interfaz de usuario web para la operación y gestión de robots.

## ¿Cómo funciona?

CYCLO se divide en varias partes clave: Cyclo Intelligence para la recopilación de datos y entrenamiento de políticas, Cyclo Control para el control de movimiento con límites de articulación y evitación de colisiones, Cyclo Lab para la simulación de entrenamiento y Cyclo Manager para la gestión de robots. Estas partes se integran de manera fluida gracias a la compatibilidad con ROS 2, Zenoh, Hugging Face y otras herramientas.

## ¿Por qué importa?

CYCLO simplifica el proceso de desarrollo de sistemas de inteligencia física, permitiendo a los desarrolladores entrenar políticas y desplegarlas en hardware real de manera eficiente. Esto puede aplicarse en diversas áreas, como la robótica industrial, la automatización y la investigación en inteligencia artificial.

## Consejo técnico

Si deseas empezar a trabajar con CYCLO, comienza por revisar la documentación oficial y el código en GitHub. Puedes empezar con la creación de un proyecto de inteligencia física utilizando Cyclo Intelligence y luego integrar Cyclo Control para el control de movimiento.

```bash
git clone https://github.com/ROBOTIS-GIT/cyclo.git
```

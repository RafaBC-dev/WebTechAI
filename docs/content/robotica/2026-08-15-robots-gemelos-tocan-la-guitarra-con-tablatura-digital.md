# Robots gemelos tocan la guitarra con tablatura digital

**Fecha:** 2026-08-15

**Título original:** Twin Guitar-Playing Robots Will Work for Tab

## Introducción

Un ingeniero ha creado robots que pueden tocar la guitarra de manera sincronizada, usando tablatura digital como guía. Este proyecto podría revolucionar la música y la robótica.

## ¿Qué es?

El MegCell Pulse es un sistema de robótica que consiste en dos robots que trabajan en conjunto para tocar la guitarra, cada uno con una función específica: uno hace el fretting y el otro hace el plucking. El sistema utiliza tablatura digital para guiar el movimiento de los robots.

## ¿Cómo funciona?

El MegCell Pulse utiliza un sistema de engranajes, actuadores magnéticos y brazos dentro de una estructura 3D impresa. Los robots pueden moverse a lo largo de la cuerda de la guitarra, pero no pueden cambiar de posición en la tabla de afinación. El sistema utiliza software de control para sincronizar el movimiento de los robots.

## ¿Por qué importa?

Este proyecto podría revolucionar la música y la robótica, permitiendo la creación de música original y sincronizada de manera automática. También podría ser utilizado en la educación musical y en la investigación en robótica.

## Consejo técnico

Si deseas crear un proyecto similar, puedes descargar los planes digitales del MegCell Pulse desde el sitio web de Kickstarter, que incluyen archivos de impresión 3D, una guía de ensamblaje y el software de control.

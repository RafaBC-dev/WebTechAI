# Un robot de playa personalizado para transportar tu equipaje con facilidad

## Introducción

Un ingeniero ha creado un robot de playa remoto controlado para facilitar la tarea de transportar equipaje pesado por la arena. Este proyecto es relevante para aquellos que disfrutan de pasar tiempo en la playa y necesitan una solución práctica para llevar sus pertenencias.

## ¿Qué es?

El robot de playa es un vehículo remoto controlado que utiliza un sistema de motores para moverse por la arena. Está diseñado para transportar equipaje pesado, como coolers, toallas y sillas, de manera fácil y eficiente.

## ¿Cómo funciona?

El robot de playa está basado en un rack de carga de una bicicleta eléctrica y utiliza dos motores para mover los ruedas traseras de manera independiente. Esto permite una dirección diferencial sin necesidad de un sistema de dirección complejo. El robot también cuenta con luces de noche, un botón de inicio que controla un relé para los motores y electrónica, y un sensor de tiempo de vuelo para evitar obstáculos.

## ¿Por qué importa?

Este robot de playa es importante porque resuelve el problema de la fatiga y el esfuerzo necesario para transportar equipaje pesado por la arena. También puede ser utilizado en áreas con dificultades de acceso, como la playa de los Grandes Lagos.

## Consejo técnico

Si deseas crear un robot de playa similar, considera utilizar la plataforma ESP32 como centro de control y desarrollar una aplicación móvil para controlar el robot de manera remota.

```bash
git clone https://github.com/espressif/ESP32
```

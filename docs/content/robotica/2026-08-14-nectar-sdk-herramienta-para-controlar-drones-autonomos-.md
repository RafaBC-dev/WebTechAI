# Nectar SDK: Herramienta para controlar drones autónomos con ROS 2

**Fecha:** 2026-08-14
**Categoría:** robotica
**Tags:** robotica, drones, ia-local
**Título original:** Nectar SDK: ROS 2 companion stack for autonomous UAVs

## Introducción

El equipo de Black Bee Drones de la Universidad Federal de Itajubá (UNIFEI) en Brasil ha desarrollado Nectar SDK, una herramienta para controlar drones autónomos con ROS 2. Esta herramienta permite controlar, cámaras y percepción desde una sola interfaz, lo que facilita la programación y el desarrollo de misiones.

## ¿Qué es?

Nectar SDK es una herramienta de código abierto desarrollada en Python que utiliza ROS 2 para controlar drones autónomos. Permite controlar diferentes tipos de drones, cámaras y sensores, y ofrece una interfaz para programar y ejecutar misiones. La herramienta se enfoca en la creación de un entorno de desarrollo unificado para controlar drones autónomos.

## ¿Cómo funciona?

Nectar SDK utiliza ROS 2 como base para controlar drones autónomos. La herramienta ofrece una arquitectura modular que permite controlar diferentes tipos de drones, cámaras y sensores. La herramienta utiliza una interfaz de programación de aplicaciones (API) para interactuar con el drone y realizar tareas como el vuelo, la navegación y la visión.

## ¿Por qué importa?

Nectar SDK importa porque ofrece una herramienta unificada para controlar drones autónomos, lo que facilita la programación y el desarrollo de misiones. La herramienta también ofrece una interfaz para programar y ejecutar misiones, lo que permite a los desarrolladores crear aplicaciones más complejas y personalizadas.

## Consejo técnico

Si estás desarrollando un proyecto de drones autónomos, considera utilizar Nectar SDK para controlar tu drone. La herramienta ofrece una arquitectura modular y una interfaz de programación de aplicaciones (API) para interactuar con el drone. Puedes empezar utilizando el comando `nectar init` para inicializar la herramienta y luego utilizar la API para controlar tu drone.

```bash
nectar init
```
